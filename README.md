## What the program does
`advancedPandas.py`:

1. Prints my Student ID.
2. Stores a pretend classroom roster of 10 students in a NumPy array.
3. Uses `pd.MultiIndex.from_product()` to make an index that pairs each student with Math and Science.
4. Builds a DataFrame of each student's grade in both subjects.
5. Displays the DataFrame.
6. Groups the grades by subject and finds the mean (Math 88.0, Science 87.0).
7. Shows the subject averages in a vertical bar graph.

## How to run
Install pandas and matplotlib with `pip install pandas matplotlib`. Then open the file in Python IDLE and choose **Run > Run Module**.
